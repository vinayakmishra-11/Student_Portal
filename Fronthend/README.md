Frontend: Vite + React app

Location: `Fronthend/vite-project`

Commands

```bash
cd Fronthend/vite-project
npm install
npm run dev
```

Notes
- Ensure the backend is running (default at http://127.0.0.1:8000) so the frontend can call the API.
- If you change the backend host/port, update the axios URLs accordingly.
